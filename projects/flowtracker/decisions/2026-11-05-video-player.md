# 视频卡片当前决定

日期：2026-11-05。状态：本轮要求已实现，等待使用反馈。

| 内容 | 当前选择 | 来源 |
| --- | --- | --- |
| 媒体比例 | 使用视频本身比例，支持等比缩放 | 用户认为视频尺寸像被固定 |
| 描述入口 | 视频左下角线条图标，悬停效果沿用下载箭头 | “模仿我之前那个下载箭头，放上去的变化” |
| 描述展开 | 视频下方相连的白色区域，与视频等宽 | “点击后是直接往下加一个白色的框” |
| 描述排版 | 文字居中，高度随内容变化 | “白色框的尺寸是根据文字来定的，文字左右居中”及之后对相连白框的纠正 |
| 空白描述 | 不显示占位文字，仍可编辑 | 用户指着“添加视频描述…”要求删除 |
| 中央播放按钮 | 删除 | “中间的播放按钮删掉” |
| 播放快捷键 | 单独选中视频后空格切换播放/暂停 | “通过选中后的空格键来播放和暂停就好” |
| 缩放柄 | 去掉突出的圆形白底，使用轻量小角标 | 用户指出右下角与其他角的大小不协调 |

## 已被替代的方案

- 常驻的描述输入框：视觉太重，并非按需展开。
- 与视频分离的浮动气泡：用户明确否定，不能再次作为默认描述方案。
- 描述图标的白色圆底、悬停方形底色：用户要求与下载箭头一样，只显示线条图标。
- 原生浏览器控制栏：用户认为默认样式不好看，改为轻量自定义控制条。
- 自定义播放器的中央半透明播放按钮：本轮已明确要求删除。
- 右下角缩放柄的突出白色圆底：本轮要求改为与角标协调的处理。

## 验证范围

验证中央按钮不存在；单选视频时空格播放/暂停、长按不反复切换；未选中时空格不启动视频；编辑描述时不拦截文字空格。原有播放、暂停、进度拖动、静音、描述保存和缩放行为继续检查。

这些检查验证实现行为，不代替用户对视觉效果的验收。
