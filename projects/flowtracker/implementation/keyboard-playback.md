# 单选视频后的空格播放

适用栈：FlowTracker、React、React Flow、HTMLVideoElement。这是实现说明，不是要求其他软件采用同一套代码。

当前实现位置：应用仓库的 `src/tracking/app/_components/Canvas/nodes/FileNode.tsx`。缩放柄在 `nodes/shared.tsx` 中提供，视频的视觉覆盖放在 `styles/file-node.css`。

## 事件优先级

1. 仅单独选中一个视频时接管 Space；视频处于全屏时也支持。
2. 输入框、描述 textarea、可编辑正文、按钮、链接保留原本的键盘行为。
3. 带修饰键的组合键不接管。
4. 捕获阶段消费 Space，避免同一次按键又触发画板平移。
5. 长按产生的 repeat 事件只消费，不反复切换播放状态。
6. 组件卸载或取消选中后移除监听，不影响其他画板。

不要仅在 video 标签上监听空格：卡片可能被选中，但焦点还在画板容器上。也不要无条件建立全局播放快捷键，这会影响描述输入和空画板手势。

## 需要验证的操作

- 点击视频完成选择，然后空格播放，再次空格暂停。
- 多选或未选中时，不擅自播放某个视频。
- 编辑描述时，空格用于输入。
- 播放中拖动进度，静音/取消静音，进入/退出全屏。
- 展开描述后，实际卡片高度、连线和缩放边界对应真实布局。

应用中使用 `npm run test:video` 做隔离 Electron 集成检查。涉及视觉的结果还需要看实际渲染；自动检查通过不表示用户已经认可。
